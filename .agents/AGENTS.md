# Project Rules: ThreeJSINT

## Aesthetic & Coding Standards
- **No Emojis**: Strictly forbid the use of emojis in all project files, UI elements, labels, and code. Use clean inline SVGs or concise typographic text symbols instead.
- **UI Aesthetics**: Professional game engine interface aesthetics (Unity / Unreal dark themes, crisp 1px borders, consistent paddings, no accidental horizontal scrolling).
- **Code Organization**: Organize JavaScript classes using `#region` strictly.
- **No Code Comments**: No code comments unless specifically requested.
