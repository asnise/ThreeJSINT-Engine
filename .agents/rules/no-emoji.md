# Rule: No Emojis

Strictly forbid the use of emojis in this project:
1. Do NOT use emojis in source code, HTML, CSS, JavaScript, UI components, labels, buttons, or console outputs.
2. Use clean, lightweight inline SVGs or concise text symbols (e.g. `✕`, `▲`, `▼`, `+`, `−`, `[V]`, `[H]`) for icons and visual indicators.
3. Keep all UI professional, clean, and consistent with modern game engine tools (Unity / Unreal aesthetics).
